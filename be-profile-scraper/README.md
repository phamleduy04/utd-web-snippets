## UTD CS Profile Scraper

This is a simple script to scrape [BE Faculty List](https://be.utdallas.edu/people/faculty/) and parse the data into a csv file.


## Development Notes
- Need to scrape the list of urls of personal faculty pages from the main page.
- Then scrape each faculty page to get the full profile information.


### Usage
0. Requires Node.js
1. Clone the repository and cd into the directory (cd cs-profile-scraper)
2. Install dependencies `npm install`
3. Run the script `node index.js`

### Output
The output will be saved to `output.csv`
